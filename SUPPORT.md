# Support for `markurtz`

Thanks for your interest in this project! If you need help, the options below will get you to the right place.

## Security Vulnerabilities

> [!IMPORTANT]
> **Please do not report security vulnerabilities through public GitHub issues.**

If you have found a security vulnerability, please refer to the [Security Policy](SECURITY.md) for instructions on how to securely report it.

## Where to Find Help

Before reaching out, please check the following resources:

- **[README](README.md) and [Development Guide](DEVELOPING.md):** Setup instructions, the command reference, and the CI/CD architecture.
- **[GitHub Issues](https://github.com/markurtz/markurtz/issues):** Search existing issues to see if someone else has already reported your problem or requested your feature.

## Opening a New Issue

If you cannot find an answer, please [open a new issue](https://github.com/markurtz/markurtz/issues/new/choose) with the template that fits:

| Issue Type             | Description                                                                          |
| :--------------------- | :----------------------------------------------------------------------------------- |
| **Bug Report**         | Something on the website or in the repository is broken. Include steps to reproduce. |
| **Content Correction** | A typo, a broken link, or a factual error in a post or page.                         |
| **Feature Request**    | An idea or improvement. Describe your use case and the problem it would solve.       |

## Response Times

This is a personal project maintained by one person in their spare time. Support is provided on a best-effort basis and there is no commercial support.
