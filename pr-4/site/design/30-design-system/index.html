    30 · Design system¶

    Status: Locked (brand system 1.0 on 2026-11-20; 1.1 component decisions 2026-11-21; later updates through 2026-11-23). The source files are tokens/tokens.json (W3C Design Tokens 2025.10) and the generated tokens/tokens.css. Edit the JSON, never the CSS. The interactive brand system page is listed in sources.

    1. Idea¶

    Exploration: curious, rigorous, hands-on. A quiet, modern page (slate neutrals, hairlines, generous space) carrying hand-drawn marks: a chisel-marker monogram, marker icons and page art drawn live by the same marker over a field of rising teal lines. Teal is the one accent, used for marks, links and the primary action, never for large fills.

    3. Typography¶

    Three families, self-hosted WOFF2, subset, about 150 KB total (Locked). The mock loads them from Google Fonts; production must self-host (E5).

    Role Family Weights Where
    Display and UI Inter Display (Inter) 400, 500, 600, 700, 800 Titles, navigation, buttons, cards, ledes
    Reading Source Serif 4 400, 400 italic, 600 Body copy, post text, bios
    Meta Geist Mono 400, 500 Role lines, dates, counts, code, badges

    Fluid scale, 18 px base (--text-body 17 to 18 px), ratio about 1.2:

    Token Range
    --text-small ~14 px
    --text-body 17 → 18 px
    --text-lead 20 → 24 px
    --text-h4 … --text-h1 24 → 32, 29 → 43, 35 → 57, 42 → 76 px
    --text-display 51 → 101 px
    Page header title (.ph-title) clamp(2.1rem, 1.3rem + 2.6vw, 3.6rem), weight 800, line-height 1.04, tracking −0.035em, balanced

    Body line-height 1.6, headings 1.1. Reading measure 68 ch. Use font-display: swap with metric-matched fallbacks.

    4. Space, layout and radius¶

    • Spacing: 4 px base: 4, 8, 12, 16, 24, 32, 48, 64, 96 (--space-1 … --space-9).
    • Frame: 1200 px max (--frame), side padding clamp(16px, 4vw, 32px).
    • Grid: 12 columns at ≥ 1024 px, 8 at ≥ 640 px, 4 below (Mark's write-in).
    • Breakpoints in use: 600 (viewer strip), 640 (2-across cards), 760 (header folds into menu), 960 (4-across cards), 1024 (page-header art stacks below this).
    • Radius: --radius-sm 4 px; --radius-md 8 px for controls, buttons and cards; --radius-lg 12 px for large media (photo cards, featured band, player); --radius-full for filter pills and badges only. No pill buttons.
    • Targets: 44 px minimum for main controls (--target).
    • Elevation: none on cards (hairline border instead); --shadow-overlay only for menus, dialogs and toasts.

    6. Themes¶

    System, Light and Dark. Dark is not an inversion: surfaces step up (navy-950 → 900 → 700), links and the primary fill use teal-400, and paragraph links get an underline. Forced colours: borders and focus rings use system colours; art and icons use currentColor so they follow.

    7. Motion¶

    Token Value
    --duration-fast / base / slow 150 / 200 / 300 ms
    --ease-out cubic-bezier(.2,.7,.2,1)
    --ease-in-out cubic-bezier(.6,0,.2,1)

    Interface motion is limited to opacity and transform. View transitions fade between pages. Art motion has its own rules (33). prefers-reduced-motion: reduce sets every duration to 0 and art to stills.

    8. Tokens pipeline¶

    design/tokens.json (W3C DTCG) → pnpm tokens → src/styles/tokens.css (custom properties with the OKLCH value in a comment). The same JSON feeds the page-art palette (--plate-line, --mk), so the art's teal matches the interface.
