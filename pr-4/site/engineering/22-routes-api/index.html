    3. API¶

    All client-area endpoints take Authorization: Bearer <token>, return JSON, and answer every access failure with 404 {"error":"link_unavailable"}. Request bodies are validated with Zod. Responses carry Cache-Control: no-store.

    GET /api/links/current¶

    Who am I: the link the bearer token opens.

    {
  "link": { "id": "Xk2p9QmZ1aBc", "name": "Smith wedding", "isRoot": true,
            "can": { "download": true, "single": true, "sets": true } },
  "collections": [{ "id": "k7Qm2xPa", "title": "Wedding gallery", "count": 412, "new": 38,
                    "nextDelivery": "full reception, about Dec 5", "cover": { "thumb": "<signed url>" } }],
  "made": [{ "id": "…", "name": "Family", "scope": "filter", "count": 64,
             "can": { "download": false, "single": true, "sets": false }, "showPreview": true,
             "active": true, "createdAt": "2026-11-23T15:00:00Z", "children": 2 }]
}

    GET /api/collections/:id¶

    Items the token covers in that collection, in timeline order, with signed URLs (one hour).

    { "collection": { "id": "k7Qm2xPa", "title": "…", "range": { "unit": "time", "from": "13:30", "to": "18:00" } },
  "facets": { "stage": ["Getting ready", "Ceremony"], "where": ["…"], "people": ["…"], "type": ["…"] },
  "moments": [{ "id": "m-ceremony", "label": "3:05 PM", "sub": "Ceremony · Garden", "at": 0.29, "items": ["<itemId>", "…"] }],
  "items": [{ "id": "…", "kind": "photo", "w": 2560, "h": 1707, "thumb": "<signed>", "preview": "<signed>",
             "takenAt": "…", "facets": { "stage": ["Ceremony"] }, "new": true, "alt": "…" }],
  "nextCursor": null }

    Paginated at 200 items (?cursor=). Shares receive the same shape narrowed to their scope.

    POST /api/links¶

    Make a share from the current link.

    { "name": "Family", "scope": "selection", "items": ["<id>", "…"],
  "filter": null, "follow": false,
  "can": { "download": false, "single": true, "sets": false }, "showPreview": true }

    scope is selection, filter (with filter and follow: true) or item (one id). Returns 201 { "id", "url": "https://<domain>/s/<id>/#<token>", "embed": "<iframe …>" }. Requires can_make_shares, or can_share_single when scope = "item" with all can false. Rate-limited per link.

    PATCH /api/links/:id¶

    Rename, change showPreview, or lower permissions on a link made from the current link. Raising a permission above the parent's is refused with 422.

    DELETE /api/links/:id¶

    Turn off a link made from the current link (or the current link itself if it is a child, from its parent's holder). Idempotent. Returns 204.

    GET /api/download¶

    ?item=<id> → 302 to a 5-minute presigned URL with Content-Disposition: attachment. ?collection=<id>&all=1 → 302 to the prebuilt zip, or 200 with a list of presigned URLs for in-browser zipping. Requires Download on the whole chain. Logs download / download_all.

    POST /api/contact¶

    { name, email, message, trap, turnstileToken, source } → validates, verifies Turnstile, rejects a filled trap silently with 200, rate-limits, stores an enquiries row, emails Mark through Resend. Returns 200 { ok: true } or 422 with field errors in words. Works without JavaScript as a normal form post that redirects to #contact-sent.

    GET /oembed¶

    ?url=https://<domain>/studio/<work>/<n>/&maxwidth=…&format=json →

    { "version": "1.0", "type": "rich", "provider_name": "Mark Kurtz", "provider_url": "https://<domain>",
  "title": "Iceland, photo 2", "author_name": "Mark Kurtz", "width": 1200, "height": 800,
  "html": "<iframe src=\"https://<domain>/embed/studio/iceland-2025/2/\" width=\"1200\" height=\"800\" title=\"Iceland, photo 2 by Mark Kurtz\" loading=\"lazy\" style=\"border:0\"></iframe>",
  "thumbnail_url": "https://media.<domain>/studio/iceland-2025/<id>/800.webp", "thumbnail_width": 800, "thumbnail_height": 533,
  "license_url": "https://creativecommons.org/licenses/by-nc/4.0/" }

    Only Studio URLs are accepted; client shares are not discoverable through oEmbed.

    Admin¶

    Server actions under src/server/actions/admin/*, each beginning await requireAdmin(): createCollection, updateCollection, tagItems, markDelivery, createRootLink, updateLink, turnOffLink, reissueLink (bumps token_version), archiveCollection, markEnquiryHandled.

    Case Response Page
    Unknown public path 404 /404 with doors and search

    Server error 500 error.tsx: "Something broke on my side. Try again, or write to me."
