Posts are MDX files in `content/blog/`. Anything Markdown can do works, plus the components listed in `docs/guides/writing.md`.

## Code

Fenced code blocks are highlighted at build time, with optional titles and line highlights.

```ts title="src/lib/example.ts" {2}
export function greet(name: string): string {
  return `Hello, ${name}`;
}
```

## Math

Inline math such as $e^{i\pi} + 1 = 0$ and display math both render with KaTeX:

$$
\mathcal{L}(\theta) = -\frac{1}{N} \sum_{i=1}^{N} \log p_\theta(y_i \mid x_i)
$$
